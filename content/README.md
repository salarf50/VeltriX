# راهنمای انتشار محتوای VeltriX

این پوشه برای محتوای قابل انتشار سایت نگهداری می‌شود. GitHub منبع اصلی کد و محتوای سبک است و Cloudflare Pages هر تغییر را خودکار منتشر می‌کند.

## مقاله‌ها

هر مقالهٔ عمومی را به‌صورت یک فایل HTML مستقل در `articles/` قرار دهید. مقاله باید عنوان مشخص، توضیح کوتاه، canonical، تصویر Open Graph و لینک بازگشت به صفحهٔ بررسی پروژه داشته باشد. برای شروع از `articles/article-template.html` استفاده کنید.

## تصاویر

تصاویر سبک و بهینه‌شدهٔ برند و نمونه‌کار در `assets/` قرار می‌گیرند. قبل از انتشار، نام فایل انگلیسی و توصیفی باشد؛ مانند `medical-mold-01.webp`. برای هر تصویر متن جایگزین دقیق بنویسید.

## فیلم‌ها

فایل‌های ویدیویی حجیم را در GitHub یا Cloudflare Pages قرار ندهید. ویدیو را در Instagram، YouTube یا فضای ویدیویی مناسب منتشر کنید و در سایت با لینک یا embed نمایش دهید. برای ویدیوهای پشت‌صحنه، عنوان، توضیح، صنعت، نوع قالب و لینک صفحهٔ اصلی VeltriX را ثبت کنید.

برای بازار ایران، مسیر پیشنهادی فعلی آپارات است. راهنمای کامل عنوان، توضیح، اطلاعات محرمانه و نحوهٔ ثبت لینک در `content/aparat-publishing.md` قرار دارد. **قانون ثابت VeltriX:** عنوان و توضیح ویدیو در سایت باید خلاصه‌ای روشن از کپشن و موضوع همان ویدیو باشد؛ هرگز از عنوان‌های عمومی مانند «اولین ویدیو» یا «دومین ویدیو» استفاده نشود.

## فایل‌های مشتری

نقشه، PDF، STEP، IGES و فایل‌های تولیدی محرمانه نباید در پوشهٔ عمومی سایت قرار بگیرند. مشتری آن‌ها را از طریق ربات تلگرام یا بله ارسال کند تا در مسیر خصوصی لید ثبت و برای ادمین ارسال شود.

## مسیر پیشنهادی انتشار

۱. تصویر یا ویدیوی عمومی را آماده و حجم آن را کم کنید.

۲. مقاله یا توضیح پروژه را در HTML بنویسید و اطلاعات فنی تأییدشده را وارد کنید.

۳. لینک مقاله را به `sitemap.xml` اضافه کنید.

۴. تغییر را در شاخهٔ `main` commit و push کنید.

۵. پس از Deploy، نسخهٔ موبایل، لینک‌ها، تصویر اجتماعی و Search Console را بررسی کنید.

## اطلاعات لازم برای هر نمونه‌کار

برای جلوگیری از ادعای نادرست، هر نمونه‌کار باید تا حد امکان این اطلاعات را داشته باشد: صنعت، نوع قالب، جنس یا رزین، تعداد کویته، ویژگی مهندسی، وضعیت پروژه و تصویر واقعی تأییدشده.
